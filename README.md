# praansu.github.io

Personal portfolio site. Next.js 16, TypeScript, Tailwind, Framer Motion, GSAP. Links to my GitHub projects and a live demo of EcoVerda.

## about this

i built this because i needed somewhere to point people when they ask what i've made. it's a single-page portfolio with my 4 featured projects, what i'm comfortable with, and how to reach me.

nothing fancy — no trackers, no cookies, no analytics. just static html served from GitHub Pages.

## how to run

clone it, install deps, run the dev server:

```
git clone https://github.com/Praansu/praansu.github.io.git
cd praansu.github.io
npm install
npm run dev
```

then open `http://localhost:3000`. build for production with `npm run build`.
