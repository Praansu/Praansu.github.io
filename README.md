# praansu-portfolio

Personal portfolio site for Praansu Karmacharya — Kathmandu-based AI Engineer building reliable small agents, computer vision systems, and geospatial hydrology.

## What this is

A static portfolio site built with Vite + React + Tailwind v4. It showcases six projects I've worked on (small-agent eval framework, nnU-Net road crack segmentation, HEC-HMS hydrology modelling, smart parking robotics, vehicle image classifier, Yatayat Go bus booking) plus experience, skills, and contact.

Not a template. No glow effects, no gradient text, no bento cards. Just an off-white system with bordered cells, mono labels, and a small 3D stage.

## Stack

- **Frontend:** React 19, Vite, Tailwind CSS v4
- **Motion:** Framer Motion (v12), GSAP, Anime.js, Lenis (smooth scroll)
- **3D:** React Three Fiber + Drei
- **UI:** Sonner (toasts), Vaul (drawers), Lucide icons
- **Fonts:** Space Grotesk, Space Mono, JetBrains Mono, Instrument Serif

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## What's inside

- `src/App.jsx` — all sections (hero, work, approach, experience, skills, contact)
- `src/components/ui/` — reusable bits (buttons, cards, dialogs, masks, marquee, ticker)
- `src/directions/swiss-mono.css` — the visual direction (off-white + near-black + amber accent)
- `index.html` — meta tags, structured data, canonical URL
